Rainbow Lab

Unreal Engine Project

A color-based puzzle game developed in Unreal Engine with C++

About The Project

Rainbow Lab is my first academic project developed with Unreal Engine, created after just a few months of learning the engine. This color-based puzzle game challenges players to solve environmental puzzles by manipulating materials and colors throughout a laboratory setting.

The game explores the relationship between colors and gameplay mechanics, requiring players to match, combine, and transform colors to progress through the laboratory chambers. Using Unreal Engine's powerful material system, I implemented dynamic color-changing mechanics that affect both the visual appearance and functional properties of objects in the game world.

This project served as an introduction to Unreal Engine development, focusing on combining C++ programming with the engine's visual tools to create an interactive and visually cohesive experience centered around color theory.

Features

  • First-person puzzle gameplay focused on color manipulation
  • Custom C++ classes for interactive elements and game mechanics
  • Dynamic material parameter manipulation through gameplay
  • Multiple puzzle chambers with increasing complexity
  • Physics-based interactions for environmental puzzle-solving

Project Information

  • Category: Academic Project
  • Project Date: 2024
  • Engine: Unreal Engine
  • Languages: C++, Blueprint
  • Focus: Material systems & gameplay
  • Showcase: YouTube

Technical Highlights

C++ Implementation in Unreal

Developed custom C++ classes that extend Unreal's actor and component system, creating interactive objects with specific behaviors. This approach allowed for more precise control over gameplay elements while learning the engine's programming framework.

Material Parameter System

Implemented a dynamic material parameter system that allows real-time modification of object appearances and properties. This core mechanic enables players to change colors and properties of objects, affecting how they interact with the environment and solve puzzles.

Puzzle Design

Created color-based puzzles that require logical thinking and understanding of color theory. Each puzzle room presents unique challenges that build upon previously introduced mechanics, creating a progression of complexity throughout the game.

Visual Feedback Systems

Designed clear visual feedback systems that help players understand the effects of their actions. Color changes, particle effects, and lighting adjustments all serve as intuitive indicators of the game state, helping players understand the puzzle mechanics without explicit instructions.

Technologies Used

Unreal Engine C++ Material Editor Blueprint Level Design Physics System Post-Processing

Learning Experience

Rainbow Lab represents my first major step into Unreal Engine development. Through this project, I gained valuable experience with the engine's architecture, workflow, and capabilities. The project helped me develop a strong foundation in:

  • Unreal's game framework and coding conventions
  • Material creation and parameter manipulation
  • Lighting and post-processing for atmospheric environments
  • Level design principles within the Unreal Editor
  • Integration between C++ and Blueprint systems

This experience has become the foundation for my continued work with Unreal Engine, informing my approach to more complex projects and specialized graphics programming within the engine.
