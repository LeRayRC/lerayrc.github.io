Asteroids

First Year Academic Project

A C++ remake of the classic Asteroids game, developed as the final project of my first year in game development.

About The Project

Asteroids is a faithful remake of the classic arcade game, developed entirely in C++ as my final project for the first academic year in video game programming. This project demonstrates fundamental programming concepts and game development techniques, focusing on clean code architecture and efficient implementation.

The game features vector-based graphics rendered through ESAT's custom graphics library, providing a nostalgic experience while introducing modern gameplay elements and user interface improvements. All game systems, including physics, collision detection, and UI components, were built from scratch as part of the learning experience.

This project represents an important milestone in my game development journey, showcasing my ability to implement core gameplay mechanics and develop complete gaming experiences with attention to both technical and user experience aspects.

Features

  • Vector-based graphics rendering using ESAT's custom graphics library
  • Complete user interface system built from scratch
  • User management with registration and authentication
  • Save/load game functionality for persistent gameplay
  • Classic Asteroids gameplay with modern improvements
  • Particle effects and visual polish

Project Information

  • Category: Academic Project
  • Project Date: 2023
  • Showcase: YouTube

Technical Highlights

Vector Graphics System

Implemented a vector-based rendering system that draws all game elements using line primitives, staying true to the original arcade aesthetic while adding visual improvements. This system required careful management of geometric transformations and efficient draw calls.

Custom UI Framework

Developed a comprehensive UI system from scratch with buttons, text fields, scroll views, and other interactive elements. This framework includes event handling for mouse/keyboard input and supports different UI states like hovering and selection.

User Data Management

Created a complete user system that allows players to register accounts, save their progress, and compete for high scores. Implemented secure data storage for persistent game data between sessions, with proper serialization and deserialization of game state.

Game Architecture

Designed a modular game architecture that separates concerns across different systems (rendering, physics, input, UI) while maintaining efficient communication between components. This approach facilitated easier debugging and feature additions throughout development.
